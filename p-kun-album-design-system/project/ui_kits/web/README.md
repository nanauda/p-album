# P-kun Album — Web UI Kit

The web prototype for parents to upload, browse, and share photos.

## Files
- `index.html` — interactive prototype (login → home → album view → upload flow)
- `App.jsx` — top-level state machine
- `Header.jsx` — sticky header with logo, search, account
- `Sidebar.jsx` — left rail with primary nav
- `AlbumGrid.jsx` — grid of album cards on home
- `AlbumView.jsx` — single album page with photo grid
- `PhotoTile.jsx` — single photo with hover zoom
- `UploadModal.jsx` — drag-and-drop upload sheet
- `HistoryFeed.jsx` — chronological "what's new" feed
- `Mascot.jsx` — P-kun reusable
- `FAB.jsx` — floating upload button
- `LoginScreen.jsx` — entry/onboarding screen

## Run
Open `index.html` directly. All state is in-memory.

Built from-scratch (no source codebase). Components match the foundations in `colors_and_type.css`.
